가상네트워크 - 중앙화 된 관리, 하드웨어 엔트포인트와 소프트웨어의 결합 ( geneve는 이 가상 네트워크 상에서의 유동성(changing capabilities)을 강조함)

vlan - ieee 802.1q
vxlan - rfc7348
nvgre- rfc 7634 

encapsulation <- 언더레이 네트워크의 분리 와 두 도메인의 간단한 연결의 중심
network virtualization  <- 분산된 환경에서의 연결성에 좀 더 초점이 맞춰있음
기존 네트워크는 vlan(12bit)를 사용하여 네트워크 내부의 디바이스를 분리하는 것에 초점이 맞춰있었음, 하지만 데이터 센터와 같은 가상네트워크의 측면에서 12(4096)비트를 사용하는 것은 부족했고, 이를 극복하기 위한 대다수의 네트워크 프로토콜은 최소 24bit 정도의 identifier을 사용했는데, 이는 여러 메타데이터를 함께 수집하기엔 부족했음. 또한 각각의 프로토콜이 각자 가지고 있는 고유한 문제들을 해결하기 위해 개발 되었기 때문에, 하드웨어와 소프트웨어 상의 변화들을 수용하기 어려움이 있었음
