**컴파일러란**
언어 번역기의 일종
(원시 프로그램(고급 언어)-> 목적 프로그램(저급언어, 어셈블리, 기계어))
인간이 다루기 편한 고급언어를 cpu가 이해할 수 있는 컴퓨터 언어로 변환하는 도구

대표적으로 컴파일러, 인터프리터 가 있음 

**컴파일 언어(ex. c, c++)**
빠른 실행 속도
소스코드를 제공하지 않아도 됨
상대적으로 복잡한 실행 과정

**인터프리터 언어(ex. python)**
상대적으로 느린 실행속도
소스코드를 제공해야 함
간단하게 실행 가능

**컴파일 과정**
- 전단부: 분석
- 후단부: 생성

**전단부: 분석과정**
- **어휘 분석(lexical): 토큰 단위로 구분** 
  원시코드를 의미가 있는 최소 단위인 토큰의 array로 unparsing 하는 과정
- **구문 분석(syntactic) : parse tree 생성**
  문장의 구조, syntax 를 분석, 트리 형태로 출력함
- **의미 문석(semantic)**
**후단부: 생성과정**
- **중간 코드 생성**
- **코드 최적화(지역 최적화, 전역 최적화)**
- **목적 코드 생성**
